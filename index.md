# DoubleCNN for Multivariate Time Series Forecasting (MTSF)

DoubleCNN is a convolutional neural network model proposed by **[lyingloong (Hao Wang)](https://github.com/lyingloong)** for time series problems as part of the **Undergraduate Research Program (2025-2026 academic year-USTC)**.
